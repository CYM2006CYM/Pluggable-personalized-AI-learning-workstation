# 测试材料说明

本目录用于展示 Pi Study Helper 的测试设计、三类学习者复现输入和已完成的端到端运行记录。

## 建议阅读顺序

1. 阅读 `01-测试方案与评价口径/测试方案与指标口径.md`，了解评价目标、指标定义和记录方法。
2. 按 `02-差异化学习者测试用例/三组差异化学习者测试用例.md` 的步骤，在网页中分别复现三类学习者。
3. 查阅 `03-端到端运行结果与过程证据/`，核对三组案例的完成情况、运行耗时和多智能体协同过程。

## 目录说明

- `01-测试方案与评价口径`：评价维度、计算口径、执行要求及核心指标对照结果。
- `02-差异化学习者测试用例`：基础薄弱、中等基础和高基础学习者的操作用例及输入记录。
- `03-端到端运行结果与过程证据`：三组案例的完整运行轨迹、耗时汇总和脱敏后的多智能体过程记录。

## 使用说明

复现时请使用项目当前版本启动本地服务，并为每个案例创建新的学习会话。材料中的会话编号、运行编号和哈希用于核验记录对应关系；其中的过程记录不包含 API Key、隐藏测试、参考实现或原始代码提交。
