## 1. 本周唯一目标

把W4真实API闭环补成无需人工修改后台文件的本地比赛MVP：Web和TUI共享同一会话，Node.js/Python完成权威代码提交，Pyodide只作为可关闭的公开预览候选，三类学习者形成可观察差异，并第一次完整走通`development-20`评测彩排。

本周不实现生产级恶意代码沙箱、外部评测器、多用户服务、完整AI代码题、SSE、GoA/OAEO或在线部署。进入第六周后禁止新增功能。

## 5. 上传锁与证据纪律

- 正式上传顺序固定为D1 `A→C`、D2 `A→E`、D3 `C→B`、D4 `A→E`、D5 `D→E`、D6负责人；E的D1准备材料不构成正式上游，也不得申请正式结论。
- 未获负责人明确授权不得commit或push；禁止强推、回退他人文件或清理本地受保护材料。
- 每次申请上传锁必须报告`W5_START_COMMIT`、实际HEAD/origin、正式上游、输入seal、拟提交清单、定向/受影响/全量测试和未证明能力。
- 正式Git只包含源码、测试、最小结构化证据和交接单；ZIP、sidecar、原始大日志、`.demo-data`、`.demo-build`、浏览器缓存、虚拟环境和真实Key不入库。
- 命令证据记录命令、工作目录、UTC起止、退出码、通过/失败/跳过数及stdout/stderr SHA-256。首次失败不得删除，修复后追加复验。

## 6. 公共完成定义

每个岗位必须一次性交付：实现或资产、作者测试、受影响回归、结构化命令结果、逐文件SHA-256、已知限制、交接单和精确拟提交清单。候选保持`NOT_COMMITTED/NOT_PUSHED/uploadLock=NOT_REQUESTED`直到负责人授锁。

统一聚合命令至少包括：

```powershell
npm.cmd run typecheck
npm.cmd test -- --maxWorkers=1
npm.cmd run check:docs
npm.cmd run build:web
npm.cmd run smoke:extension
npm.cmd run check:release
npm.cmd run verify
git diff --check
```

Python评测相关项只在Node `v22.23.1`、npm `10.9.8`、Python `3.13.7`、Pandas `3.0.5`且`PYTHONNOUSERSITE=1`的独立环境中形成正式结论。

## 7. W5 Go/No-Go

只有V5-1至V5-8全部PASS、干净目录Web与TUI各完成一条闭环、三案例差异合法、Node正式提交连续稳定、刷新/重启/模型失败可恢复、安全扫描零敏感命中、`development-20`六环节和彩排指标可复算、页面文案与发布边界已由负责人冻结、盲评回避安排已签署、第六周人员与材料明确时才可GO。

Pyodide在D3被关闭不单独阻塞W5 GO，但关闭后页面必须没有死入口，Node正式提交仍可用。Monaco默认关闭，不影响W5 GO。
