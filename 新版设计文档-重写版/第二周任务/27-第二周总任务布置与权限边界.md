## 5. 单仓库上传规则

继续使用一个仓库、默认分支、无个人分支和一把上传锁。正常流程中每个岗位只安排一次正式上传；B为保证B/E原始gold互不可见，固定分成D5资产上传和D6原始标注上传两次，这是唯一预先批准的组员例外。负责人固定在D1上传任务包、D7上传最终gold与门禁签署。所有上传严格串行。

```text
申请上传锁
→ 负责人确认当前持锁人为“无”
→ git status确认只含本人范围
→ 【拉取】默认分支最新提交
→ 检查同路径冲突
→ 重跑本人最小测试和受影响回归
→ 只暂存本人交付
→ commit并【上传】
→ 报告提交号、测试和文件清单
→ 负责人确认后释放上传锁
```

拉取到新提交后必须重新测试。发现同文件冲突、公共合同冲突或远端变化时停止上传，不得强推、覆盖或删除他人文件。
