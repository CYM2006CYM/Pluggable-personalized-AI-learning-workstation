# 提交材料统一口径与待填数据清单

> 用途：保证作品介绍、设计方案、PPT、视频、README、测试报告和案例材料使用同一事实
> 使用方法：最终候选冻结后逐项填写；未取得证据的字段保持`NOT_RUN`、`OPEN`或`DEFERRED`

## 1. 一句话统一口径

> Pi Study Helper是一套面向职业技能学习的可插拔个性化学习工作台：以Profile固定可信专业知识与评测边界，以确定性程序保障学情事实、合法路径和权威判分，以多智能体完成资源生成、风险质疑、争议辩护、最终裁决和个性化解释，并根据持续学习证据动态调整后续学习。

## 3. 功能状态词典

所有材料只使用以下状态：

| 状态 | 含义 |
|---|---|
| `VERIFIED` | 已在最终候选版本运行，证据可复算 |
| `IMPLEMENTED_PENDING_FINAL_VERIFY` | 代码或资产已实现，但最终候选尚未完成整体验收 |
| `PLANNED` | 已设计但尚未完成实现 |
| `OPEN` | 已知问题，仍需修复 |
| `BLOCKED` | 有明确外部或前置阻塞 |
| `NOT_RUN` | 测试或真实模型调用尚未执行 |
| `DEGRADED` | 主能力不可用，当前使用明确的降级路径 |
| `OUT_OF_SCOPE` | 不属于本次MVP |

禁止把`IMPLEMENTED_PENDING_FINAL_VERIFY`简写成“已全面通过”，也禁止把`NOT_RUN`写成目标值已达成。

## 9. PPT与视频统一检查

- 页面截图与演示视频来自最终候选提交；
- 视频中显示的Profile revision、模型状态和报告一致；
- 实时题必须有真实请求、响应、审核轨迹和`LIVE_MODEL`证据；
- 固定保障题必须明确标记，不能剪辑成实时成功；
- Agent时间线与服务端实际运行顺序一致；
- 案例输入、路径、正文版本、题组和总结属于同一会话；
- PPT中的指标能回到分子、分母和原始证据；
- 视频总时长不超过10分钟；
- 不展示API Key、个人信息、绝对路径、hidden tests或参考实现。

## 10. README与部署统一检查

- 支持的操作系统和环境版本明确；
- 每条终端命令可直接执行，路径和环境变量说明完整；
- API Key只在当前终端或本地安全配置中提供；
- 清楚区分默认录制/离线模式和实时API模式；
- 从干净环境完成安装、启动、创建会话和一个活动；
- 记录实际启动URL、命令退出码、问题和处理方式；
- 不要求评委拥有开发者本机的绝对路径或缓存目录。

## 11. 最终安全审计

对实际提交压缩包解压后扫描：

- API Key、Token、`.env`和认证信息；
- 本机绝对路径；
- 姓名、联系方式和未脱敏会话数据；
- hidden tests、reference solution、私有Rubric和私有期望输出；
- Agent系统提示词和私有上下文；
- 临时日志、缓存、测试残留和编辑器文件；
- 与最终提交号不一致的截图、报告或构建产物。

## 12. 已知限制统一表述

1. 当前只完整交付Pandas数据清洗领域；
2. 多Agent采用串行隔离协作，不是并行群体网络；
3. Node/Python执行器面向本地受信任测试，不是生产级恶意代码沙箱；
4. Pyodide公开预览关闭，不参与权威判分；
5. 实时模型不可用时使用明确标记的固定保障题和确定性摘要；
6. 未执行的正式指标、真人试测或现场模型调用必须标记`NOT_RUN`；
7. Profile合同提供迁移能力，但当前不宣称第二领域已经完成。
