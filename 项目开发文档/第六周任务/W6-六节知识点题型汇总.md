# 六节知识点题型汇总

## 说明

本表按当前 `pandas-cleaning-revision-3-draft` 的正式活动资产整理。这里的“六个章节”实际对应 Pandas 数据清洗资料包中的六个知识小节，分布在三个内容章节中。

客观题的运行来源为：

```text
ai_generated + profile_fixed
```

含义是：优先尝试根据当前教学正文调用 AI 生成并经过审核的题组；模型不可用、超时或审核不通过时，使用固定题保障。固定题不是实时 AI 生成结果。

## 总览表

| 小节 | 知识点 | 客观题 | 主观/代码题 | 当前活动 ID |
|---|---|---|---|---|
| 01 | 读取 CSV | 理解检查客观题 | 代码补全 | `act-read-csv`、`act-load-csv` |
| 02 | 检查 DataFrame 结构 | 理解检查客观题 | 代码补全 | `act-quiz-inspect-dataframe`、`act-inspect-dataframe` |
| 03 | 处理缺失值 | 理解检查客观题 | 代码补全 | `act-quiz-missing-values`、`act-missing` |
| 04 | 处理重复订单 | 理解检查客观题 | 代码补全 | `act-quiz-duplicate-orders`、`act-duplicates` |
| 05 | 规范类型与格式 | 理解检查客观题 | 代码补全 | `act-quiz-type-format`、`act-types` |
| 06 | 验证清洗结果 | 理解检查客观题 | 综合独立实操 | `act-quiz-validate-result`、`act-practical` |

## 01 读取 CSV

### 客观题

- 活动：`act-read-csv`
- 类型：`mcq`
- 内容：检查是否理解 `pandas.read_csv`、`csv_path`、字符串 dtype，以及读取阶段不提前清洗的边界。
- 来源：`ai_generated`，失败时 `profile_fixed`。

### 代码题

- 活动：`act-load-csv`
- 类型：`code_completion`
- 入口函数：`load_orders(csv_path)`
- 要求：读取评测器提供的 UTF-8 CSV，返回保留七个合同列、行数、行顺序和原始文本的 DataFrame。
- 关键要求：使用 `dtype="string"`，不填充缺失值、不去重、不转换金额和日期。

## 02 检查 DataFrame 结构

### 客观题

- 活动：`act-quiz-inspect-dataframe`
- 类型：`mcq`
- 内容：检查列名、列顺序、行数、`DataFrame` 复制，以及结构检查和数据清洗的区别。
- 来源：`ai_generated`，失败时 `profile_fixed`。

### 代码题

- 活动：`act-inspect-dataframe`
- 类型：`code_completion`
- 入口函数：`inspect_orders(df)`
- 要求：生成一个副本，只保留合同规定的七列并按固定顺序排列，不修改原始 DataFrame。

## 03 处理缺失值

### 客观题

- 活动：`act-quiz-missing-values`
- 类型：`mcq`
- 内容：识别不同字段的缺失处理规则，以及为什么不能用同一个默认值处理所有列。
- 来源：`ai_generated`，失败时 `profile_fixed`。

### 代码题

- 活动：`act-missing`
- 类型：`code_completion`
- 入口函数：按题面合同完成缺失值处理函数。
- 要求：按固定业务规则处理 `order_id`、`customer_id`、`amount`、`order_date` 和 `note` 的缺失；保留合法记录和规定的字段类型。

## 04 处理重复订单

### 客观题

- 活动：`act-quiz-duplicate-orders`
- 类型：`mcq`
- 内容：理解 `order_id` 去重、日期优先级、重复记录选择和稳定结果。
- 来源：`ai_generated`，失败时 `profile_fixed`。

### 代码题

- 活动：`act-duplicates`
- 类型：`code_completion`
- 要求：对重复 `order_id` 按可解析日期、最新日期、原始第一条的固定优先级选择记录，并保持被选记录的原始相对顺序。

## 05 规范类型与格式

### 客观题

- 活动：`act-quiz-type-format`
- 类型：`mcq`
- 内容：理解金额、日期、城市、状态和普通文本列的规范化方式，以及 dtype 和业务取值的区别。
- 来源：`ai_generated`，失败时 `profile_fixed`。

### 代码题

- 活动：`act-types`
- 类型：`code_completion`
- 要求：完成金额、日期、城市、状态和字符串列的类型与格式规范化，并满足题面规定的不变量。

## 06 验证清洗结果

### 客观题

- 活动：`act-quiz-validate-result`
- 类型：`mcq`
- 内容：理解如何验证七列结构、主键唯一性、缺失值、dtype、业务取值和行顺序。
- 来源：`ai_generated`，失败时 `profile_fixed`。

### 综合独立实操

- 活动：`act-practical`
- 类型：`coding_practical`
- 入口函数：`clean_orders(df)`
- 要求：把前面几节的结构检查、缺失处理、稳定去重、类型规范化和结果验证连成完整清洗流程。
- 判定：使用正式 Node/Python 评测、公开测试、hidden tests 和确定性 Rubric；通过后才形成正式活动结果。

## 额外的 Python 基础补救题

这道题不属于 Pandas 六个知识小节，而是在诊断发现 Python 基础不足时使用：

- 活动：`act-basic-python-remediation`
- 类型：`mcq`
- 题型：单选题（`single_choice`）
- 内容：变量、属性和方法调用，例如正确理解 `df.shape` 与 `df.shape()` 的区别。

## 当前题型结构结论

当前六节合计：

| 统计项 | 数量 |
|---|---:|
| 客观题活动 | 6 |
| 代码补全活动 | 5 |
| 综合独立实操活动 | 1 |
| Python 基础补救客观题 | 1（不计入六节） |

因此，当前结构不是“每一节都同时有客观题、代码补全和独立实操”，而是：

```text
六节都有客观题
第 1～5 节各有一个代码补全
第 6 节有一个综合独立实操
```

这符合当前固定活动资产的分工：代码补全用于逐步练习，最后一节的独立实操用于综合验收。若负责人后续裁决为“六节每节都必须同时拥有代码补全和独立实操”，那属于新增范围，需要另行修改活动资产、测试资产、Rubric、路径和验收证据，不能把当前汇总表当成已经完成该要求。

## 题目来源与判分边界

- 客观题：由实时 AI 生成时，题面应绑定当前小节正式教学正文，并经过 Generator → Hunter → Defender（高风险时）→ Judge 审核；AI 不可用时固定题兜底。
- 代码补全：当前使用固定题面、固定公开/隐藏测试和 Node/Python 正式评测，不由实时 AI 改写判分合同。
- 综合独立实操：使用固定任务资产、hidden tests 和 Rubric 进行权威判分，不使用浏览器预览结果作为掌握度证据。
- 所有题型都应保留当前 Session 的章节、资料包 revision 和活动快照绑定，刷新或恢复不能静默替换题面。
