## 二、发现与处理

### SEC-001：npm包夹带私有评测资产

- 规则：发布包不得携带答案、hidden tests、Rubric、reference solution、私有样例或构建缓存。
- 严重级别：严重。
- 位置：`pi-study-helper/package.json:9`；`pi-study-helper/scripts/check-release.mjs:12`。
- 证据：修复前 `npm pack --dry-run --json` 共330项，清单中包含私有评测目录和 `src/web/node_modules/.vite` 缓存。
- 影响：任何获得 npm 包的人都可能提取权威答案或密封评测资产，破坏评测可信度。
- 修复：发布白名单从整个 `fixtures/profiles` 收紧为 `fixtures/profiles/demo-review`；新增 `src/.npmignore` 排除 Web 缓存；release 检查只允许四个批准路径。
- 复验：修复后138项，`private / hidden / rubrics / reference-solutions / answer-key / gold / node_modules` 命中数为0；revision 2和revision 3正式评测Profile均未进入npm包。
- 状态：`RESOLVED / VERIFIED_BY_PACK_DRY_RUN`。
